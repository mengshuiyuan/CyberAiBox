# 双屏板使用Left目录表情指南

## 概述

本指南介绍如何配置双屏板，使其使用项目根目录下`left`文件夹中的表情资源，而不是默认的表情资源。

## 准备工作

### 1. 准备表情资源

目前使用同显方案，由`left`文件夹下存放要求的gif表情
在项目根目录下`left`文件夹，并将您想要使用的表情GIF文件放入其中。每个表情文件应符合以下要求：

- 文件格式：GIF
- 尺寸：160x160像素
- 命名规则：使用表情名称作为文件名，例如：`happy.gif`、`sad.gif`等
- 支持的表情名称：
  - neutral
  - happy
  - laughing
  - funny
  - sad
  - angry
  - crying
  - loving
  - embarrassed
  - surprised
  - shocked
  - thinking
  - winking
  - cool
  - relaxed
  - delicious
  - kissy
  - confident
  - sleepy
  - silly
  - confused

### 2. 确保项目结构正确

```
/esp-project/binocular-display-of-lily-rabbit/
├── left/
│   ├── happy.gif
│   ├── sad.gif
│   └── ... 其他表情文件
├── main/
├── scripts/
└── ... 其他项目文件
```

- 增强表情加载逻辑，确保能够从left目录加载表情

## 构建和烧录

### 1. 构建固件

在项目根目录下执行以下命令构建固件：

```bash
idf.py build
```

构建过程中，系统会自动检测`left`目录中的表情文件，并将其包含在生成的assets.bin文件中。

### 2. 烧录固件

将设备连接到电脑，执行以下命令烧录固件：

```bash
idf.py -p /dev/ttyACM0 flash
```

（注意：请根据实际情况替换`/dev/ttyACM0`为您的设备端口）

## 验证

烧录完成后，设备会自动重启。您可以通过以下方式验证表情是否正确显示：

1. 观察设备屏幕上的表情是否为您在`left`目录中提供的表情
2. 检查设备的日志输出，确认表情是否成功加载

## 故障排除

### 表情没有显示

1. 检查`left`目录中的表情文件是否存在且命名正确
2. 检查表情文件的尺寸是否为160x160像素
3. 检查构建日志，确认表情文件是否被正确处理
4. 检查设备日志，查看是否有表情加载错误

### 构建失败

1. 检查CMakeLists.txt中的语法是否正确
2. 确保所有依赖项都已正确安装
3. 查看详细的构建日志，定位错误原因

## 注意事项

1. 表情文件的名称必须与支持的表情名称完全一致
2. 表情文件的尺寸必须为160x160像素，否则可能无法正确显示
3. 过大的表情文件可能会导致固件体积过大，影响设备性能
4. 建议使用压缩过的GIF文件，以减少固件体积

## 支持的设备

- 双屏板 (CONFIG_BOARD_TYPE_DUAL_SCREEN_CYBERAI)

## 常见问题

### Q: 我可以使用不同尺寸的表情文件吗？
A: 不建议使用不同尺寸的表情文件，因为设备的显示区域是固定的，不同尺寸的表情可能无法正确显示。

### Q: 我可以使用其他格式的表情文件吗？
A: 目前仅支持GIF格式的表情文件。

### Q: 我可以添加自定义的表情名称吗？
A: 目前仅支持预设的表情名称列表，无法添加自定义的表情名称。

### Q: 表情文件的最大大小是多少？
A: 建议单个表情文件不超过500KB，否则可能会导致固件体积过大。

## 总结

通过以上步骤，您可以成功配置双屏板使用`left`目录中的表情资源。如果您遇到任何问题，请查看构建日志和设备日志，或参考项目的其他文档。
